# 발표 스크립트

## 프로젝트 개요

저희 프로젝트는 K League 1 선수 데이터를 기반으로 한 DB 중심 이적시장 시뮬레이터입니다.
사용자는 구단을 선택하고, 이적시장에 등록된 선수를 영입하거나 기존 선수를 방출할 수 있습니다.
이 과정에서 선수 소속, 계약, 구단 예산, 이적 기록이 모두 MySQL 내부에서 함께 변경됩니다.

## DB 설계 포인트

1. `players`와 `player_stats`를 분리해 선수 기본 정보와 능력치를 정규화했습니다.
2. `contracts`는 선수와 구단 사이의 계약 이력을 저장합니다.
3. `transfer_history`는 모든 영입과 방출을 기록합니다.
4. `transfer_market`은 현재 영입 가능한 매물을 관리합니다.
5. `views`를 통해 예산, 스쿼드 점수, 이적시장 목록을 쉽게 조회합니다.

## 핵심 기능

- 선수 영입: 예산 확인, 계약 만료, 새 계약 생성, 소속 변경, 예산 변경, 이적 기록 저장
- 선수 방출: 계약 released 처리, 소속 NULL 변경, 이적 기록 저장
- 스쿼드 대결: 선수 overall 평균과 감독 rating을 기반으로 구단 점수 계산

## 강조할 DB 기능

- CHECK 제약 조건
- Foreign Key
- View
- Trigger
- Stored Procedure
- Transaction / Rollback

## 핵심 문장

선수 영입은 단순 UPDATE가 아니라 여러 테이블이 동시에 바뀌는 작업입니다.
따라서 저장 프로시저와 트랜잭션으로 묶어 하나라도 실패하면 전체 작업이 취소되도록 설계했습니다.
